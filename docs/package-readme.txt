Map — 창작용 지도·기후 편집기

[실행]
시작 메뉴(또는 바탕화면)의 "Map"을 누르세요. 이 폴더의 Map.exe 를 직접 열어도 됩니다.
따로 설치할 다른 프로그램은 없습니다(Windows 10/11, 64비트).

[기후 보기]
1. 지도를 그리거나 ☰ 메뉴에서 예제·열기로 불러옵니다.
2. 위쪽 가운데 "기후 보기"(Tab 키)를 누르고, 가운데 카드에서 계산을 시작합니다.
3. 2~5분 걸립니다. 계산은 컴퓨터를 덜 쓰도록 낮은 우선순위로 돌고, 메모리는 4 GB를 넘지 않습니다.

[폴더 안내]
- climate\ : 기후 모형과 그 실행에 쓰는 Python. 지우거나 옮기지 마세요(Map.exe 옆에 있어야 합니다).
- 계산한 기후는 지도를 저장할 때 지도 파일(.map) 안에 함께 들어갑니다. 저장한 지도를 다시 열면 기후가 바로 보입니다. 저장하지 않고 닫으면 계산한 기후도 남지 않습니다.
- 설정(테마, 글자 크기)은 %APPDATA%\TheGarden\settings.json 에 있습니다.
- 프로그램을 삭제하면 설정도 함께 지워집니다. 직접 저장한 .map 지도(그 안의 기후 포함)는 남습니다.
- 새 버전을 지우지 않고 덮어 설치하면 설정은 그대로 남습니다.

[삭제]
Windows 설정 → 앱 → 설치된 앱 → Map → 제거

[주의]
기후는 세계관용 단순 계절 기후 모형의 근사입니다. 실제 지구 기후 예측이 아닙니다.
